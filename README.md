# Reefer Dashboard 2026

Versión inicial en Streamlit del dashboard basado en `Control reefer.xlsx`.

## Publicar en Streamlit Community Cloud
1. Subir los cuatro archivos de este paquete a un repositorio privado de GitHub.
2. Crear una app en Streamlit Community Cloud conectada al repositorio.
3. Definir `app.py` como archivo principal.

> El Excel contiene información de trabajo: mantener el repositorio y el acceso a la app con la configuración de privacidad que corresponda a tu organización.
